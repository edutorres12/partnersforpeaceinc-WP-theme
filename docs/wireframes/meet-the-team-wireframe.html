1. HeaderSame as all pages. The nav item for this page is the current one.
2. HeroPhoto band with a dark wash, like the Services hero. Carries the page's ONE H1 — the bio names are H2 and the card titles H3, so the outline reads as one page about a team.
3. Roster gridThe page's index, and the reason the bios are behind a dialog. Choosing a therapist means comparing them, and six full bios stacked down a page can only be compared from memory. Here they sit side by side.

Six cards in ONE grid, not two rows of three — two column rows size themselves independently, so the second bank came out taller than the first. Each card: portrait, credential line as the eyebrow above the name, an excerpt, specialties as pills, and its own link.
4. Closing CTASame closing banner as the rest of the site. It is no longer the only place to act — every dialog carries its own CTA.
5. FooterSame as all pages.
6. & 7. The dialogNot a separate page — this is the same band that would otherwise sit in the page, promoted into a native <dialog> by assets/js/bio-modal.js.

What that buys. The browser supplies the focus trap, Escape and the backdrop. Added on top: a close button, focus returning to the card that opened it, a background scroll lock, and the dialog named by the person's heading.

What it does not cost. The bio is written into the page as real markup, so it is in the HTML for crawlers and it is the whole layout with JavaScript off — the card link is then just a jump down to the bio. Each bio keeps its #therapist-N anchor: landing on one opens it, opening one pushes the hash, so a bio stays linkable and Back closes it.

The portrait alternates side and every other band is tinted. Invisible here — a dialog shows one person — but it marks the seam between people in the no-JS layout, so the tint is dropped inside the dialog.
